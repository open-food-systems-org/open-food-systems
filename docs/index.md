# Open Food Systems

Welcome to the public home of the Open Food Systems initiative — an open, collaborative effort to explore how technology, AI, and global cooperation can help eliminate hunger.

This site will grow as the project grows. For now, it serves as the starting point for the movement.

## What this project is about
- Open knowledge  
- Open hardware  
- Open software  
- Open logistics  
- Open community  
- Open learning
